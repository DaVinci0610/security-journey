# Project 01 – ICMP Packet Analysis

## Goal

In this project, I want to fill my knowledge gaps regarding data packets,
protocols and ports. With this experiment, I begin building practical knowledge
in order to carry out more complex projects in the future.

---

## Why ICMP?

I deliberately chose ICMP as my starting point because:

- It is **not a data transmission protocol**
- It uses **no ports**
- It **establishes no connection**
- It is therefore ideal for **pure observation and understanding**

This knowledge is meant to build the **foundation** for working with real
protocols like TCP and UDP later on.

---

## Questions I Want to Answer

- What does each value in an ICMP packet mean?
- Which values exist in the first place?
- What do these values tell us?
- What does a **normal** value look like?
- What does a **forged** value look like?

---

## Approach

I captured an ICMP packet on **Kali Linux** using **Wireshark** and fully
dissected it – analyzing and documenting every single and possible value.
